# QA Automation Framework - Cypress

## Overview
This project demonstrates end-to-end (E2E) test automation using Cypress. It focuses on testing web application functionality, user workflows, and UI validation.

## Objectives
- Automate critical user flows such as login and navigation
- Validate form inputs and error handling
- Ensure application stability through repeatable tests

## Features
- Login test automation
- Negative testing (invalid credentials)
- Form validation testing
- URL and page validation
- Clean and maintainable test structure

## Tools & Technologies
- Cypress
- JavaScript
- Node.js

## Test Scenarios Covered
1. Successful login with valid credentials
2. Failed login with invalid credentials
3. Empty input field validation
4. Navigation and URL verification
